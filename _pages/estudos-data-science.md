Antes da estratégia de dados em escala e da sala de aula de oratória, houve a base técnica: os primeiros projetos de ciência de dados, feitos para aprender fazendo — regressão, classificação e processamento de linguagem natural, do zero ao modelo.

São estudos, não produtos. Ficam aqui como registro de onde essa trajetória começou.

---

### Previsão de preço de imóveis com regressão avançada

Dataset público de vendas residenciais em Ames, Iowa. O exercício: sair de uma regressão linear simples e evoluir para técnicas de regularização (Ridge, Lasso, ElasticNet) e modelos de ensemble, cobrindo o ciclo completo — análise exploratória, tratamento de valores ausentes, engenharia de variáveis categóricas e numéricas, e comparação de desempenho entre modelos.

[Ver notebook no GitHub →](https://github.com/DiegoAlves-data/DiegoAlves-data)

---

### Classificação de câncer de mama com Random Forest, PCA e SVM

Dataset clínico de diagnóstico de câncer de mama. O exercício: comparar uma abordagem de seleção de variáveis com Random Forest contra uma redução de dimensionalidade via PCA alimentando um SVM, avaliando qual caminho preserva mais sinal com menos variáveis — uma pergunta que se repete em qualquer problema real de classificação com muitas features e poucas linhas.

[Ver notebook no GitHub →](https://github.com/DiegoAlves-data/DiegoAlves-data)

---

### Detecção de spam com processamento de linguagem natural

Classificação binária de mensagens de texto (spam vs. legítima). O exercício: pipeline completo de NLP clássico — limpeza e normalização de texto, vetorização e um classificador supervisionado — como base para entender, mais tarde, onde modelos de linguagem maiores de fato agregam sobre uma abordagem simples e auditável.

[Ver notebook no GitHub →](https://github.com/DiegoAlves-data/DiegoAlves-data)

---

### Detecção de tendências de consumo em posts de redes sociais

Análise de texto em posts públicos para identificar tendências emergentes de alimentação, usando contagem de palavras, matriz de co-ocorrência e métricas de associação (Lift, PPMI) para separar ruído de sinal real — e validar se o que o método aponta como "tendência" de fato se sustenta ao longo do tempo.

[Ver notebook no GitHub →](https://github.com/DiegoAlves-data/DiegoAlves-data)
